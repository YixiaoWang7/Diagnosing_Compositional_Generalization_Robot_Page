Abstract

Sequential robot manipulation requires policies to execute novel combinations of familiar instruction components. However, collecting demonstrations for all possible instruction tuples is combinatorially expensive, while sparsely covered datasets often fail under out-of-distribution recombination. This paper studies compositional generalization through the lens of instruction-space coverage. We decompose the generalization gap into three sources: marginal instruction shift, instruction-compositional shift, and context–action shift. Our results show that exhaustive tuple enumeration is unnecessary: a structured subset, as small as one quarter of the full task space, can recover strong out-of-distribution performance when it covers action-relevant dependencies.

02 Generalization Framework

Where does the generalization gap come from? Our analysis separates three sources of distribution shift.

1. Marginal Instruction Shift

Whether individual instruction values have similar coverage and frequency in training and test data.

2. Instruction-Compositional Shift

Whether familiar subtasks are recombined in unfamiliar ways at test time.

3. Context–Action Shift

How observation–action distributions differ even after conditioning on the full instruction sequence.

05 Code & Data

The training code, simulator, and demonstration datasets for all three task families are public. Setup, data preparation, and train/evaluate commands are in the code repository README.

Code Diagnosing_Compositional_Generalization_Robot RoboPolicy learning library plus the paper's data preparation, training, and evaluation tools. Simulator robot_envs MuJoCo environments for Pick-and-Place, Pick–Place–Press, and the dependent two-stage task. Dataset cg_l4_1s Pick-and-Place (PP) demonstrations: 4 objects × 4 receptacles. Dataset cg_l5 Pick–Place–Press (PPP) demonstrations: 64 object–receptacle–button instructions. Dataset cg_l4_2s Dependent two-stage Pick-and-Place (2S-PP) demonstrations; both two-stage variants use this dataset.

Datasets are hosted on Hugging Face. Pretrained checkpoint downloads are not yet available.
